# Раздел рассылки: что разошлось с макетами

Составлено 2026-09-08 после сверки живой страницы с макетами
(https://claude.ai/code/artifact/6ac75590-aa8c-449f-a5d3-6f4f606505c8).

Сделанное — это работающий каркас: данные ходят, кнопки отрабатывают,
правка сохраняется. Но по устройству экрана я срезал углы, и это видно.
Ниже честный список расхождений, по убыванию значимости.

## 1. Недели нет — есть плоский список

**В макете:** семь строк, Пн—Вс, с датами и временем. Пустой день — тоже
строка, и в ней сразу три предложения с кнопкой «Поставить». Видно не только
что стоит, но и **чего не хватает**.

**Сейчас:** список тех записей, что оказались в очереди. Ни дней, ни пустых
слотов; если в ленте три поста, экран показывает три строки и всё.

Это главное расхождение. Смысл экрана был в том, чтобы видеть неделю
целиком, а не содержимое очереди.

**Что делать.** Строить сетку из семи дней от сегодня. День поста — из
`publish_at`, а у записей без него — из расписания канала (`daily_HH` даёт
время, порядок в очереди даёт день). Пустой слот показывать строкой с
предложениями из уже существующей ручки `/suggestions`.

**Цена:** средняя. Данные все есть, работа во фронте.

## 2. Настройки — отдельная страница, а не сворачиваемая полоска

**В макете:** свой экран. Сверху три карточки состояния (последний пост,
в очереди, опубликовано всего), ниже переключатели: автопостинг,
расписание, глубина ленты, шаблон, портреты площадок, одобрение в личке.
И блок «что остаётся за ботом» — доставка, привязка каналов, сигнал о
простое, отключённая кнопка «отправить сейчас».

**Сейчас:** сворачиваемая полоска с одним полем `feed_limit`.

**Что делать.** `app/pages/broadcast/settings.vue`. API уже умеет всё
нужное: `PATCH /channels/{id}` принимает `enabled`, `period`,
`template_code`, `feed_limit`, а `GET /channels` отдаёт `last_posted_at`,
`silent_days`, `in_feed`. Не хватает только счётчика «опубликовано всего» —
это одна строка в `channelPayload`.

**Цена:** небольшая. Почти всё готово на бэкенде.

## 3. У правки поста нет превью

**В макете:** две колонки. Слева редактор, справа — как пост увидят в
канале: аватар канала, альбом картинок, текст, время. Плюс подпись о том,
что свой текст перестаёт обновляться вслед за событием.

**Сейчас:** только textarea. Картинок не видно вовсе, хотя API их уже
отдаёт боту (`photo_urls`).

**Что делать.** Вернуть правую колонку. Картинки добавить в `itemPayload` —
на бэкенде метод `eventPhotos` уже написан, его надо позвать и отдать.
Предупреждение про «текст перестаёт обновляться» на странице есть, его
достаточно перенести в карточку.

**Цена:** небольшая.

## 4. Пул предложений без фильтров и без баланса недели

**В макете:** свой экран с поиском, фильтром по дню и теме, сортировкой
«сначала непохожие на ленту», и колонкой справа — чем занята неделя
(квесты 3, концерты 2, театр 1, выставки 0).

**Сейчас:** список под лентой, без фильтров, без баланса.

**Что делать.** Фильтры — параметры к существующей ручке. Баланс недели
считается из ленты, но нужен признак темы: сейчас в выдаче его нет,
придётся добавить интересы события в `suggestions` и `feed`.

**Цена:** средняя, из-за тем.

## 5. Мелочи, каждая на несколько строк

- **Миниатюры постеров** в строках ленты (в макете 56×42). Картинки на
  бэкенде есть, в `itemPayload` не отдаются.
- **Предупреждение про однообразие** сделано, но в макете оно называет сеть
  и предлагает кнопку «Разбавить» — сейчас только перечисляет площадки.
- **Пометка «N-й за неделю»** у постов повторяющейся сети прямо в строке.
- **Счётчик недели** в шапке: «заполнено 6 из 7, закреплено 2,
  отредактировано 1» — сейчас только `in_feed`.
- **«Следующая публикация через N ч»** — считается из расписания.

## Чего в макетах не было, а в жизни понадобилось

- Пул предлагал события, которые постановка отвергала с 409: у канала
  Воронежа 96 записей в закрытых статусах, а `UNIQUE(broadcast_id, event_id)`
  не даёт создать вторую. Починено 2026-09-08: снятое оживляется,
  опубликованное отвергается.
- Раздел открывался на выключенном канале — список каналов приходил без
  сортировки.

## Порядок

1. Недельная сетка с пустыми слотами — ради неё всё и затевалось.
2. Настройки отдельной страницей.
3. Превью в правке + миниатюры в ленте (одна работа: отдать картинки).
4. Счётчики в шапке и пометки сетей.
5. Фильтры и баланс недели в пуле — последними, они требуют тем.
